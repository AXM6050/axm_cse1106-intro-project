# Personalized Welcome Message

### This code uses printf and scanf commands in basic C to request for the user's name and generate a personalized welcome message to the cse1106 class.

## Technologies

### Run in a termianl. C code used. File name Code1.c

## How to Run

### 1. To run this code, in the terminal, type ./a.out.
### 2. The terminal will then prompt the user to type out their name.
### 3. Type user's name and hit enter.
### 4. The Welcome message should appear on the terminal.
